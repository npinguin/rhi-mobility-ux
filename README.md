# Robotix Home Intelligence Mobility UX

Public HACS Dashboard/plugin repository for Robotix Home Intelligence Mobility UX.

The first HACS migration is being prepared on `migration/hacs-current` from the legacy Mobility UX release `R22.12.11.30`. The migration preserves the public `MOBILITY_PUBLIC_RUNTIME_V1` boundary and does not authorize backend or UX semantic redesign.

Status: repository bootstrap only; do not install from `main` until the first migration RC has passed CI and HACS validation.
